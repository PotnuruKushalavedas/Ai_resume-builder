# ChainSync_ai
AI Resume & Portfolio Builder 


Build an AI application that generates ATS-friendly resumes, LinkedIn profiles, GitHub portfolio descriptions, project summaries, cover letters, and professional biographies customized for different industries and job roles. 

The project by :P. kushalavedas(24kd1a1553)
		 M.Divyasree(24kd1a1537)


Objective:
To design and implement an end-to-end AI-powered career assistance platform that transforms raw candidate information into personalized, ATS-compatible, and job-specific professional documents while providing intelligent resume analysis, job matching, skill-gap identification, and career recommendations through AI and NLP techniques developed by the project team 

Existing System :

kickresume,resume.io,MyPerfectresume ,zety
